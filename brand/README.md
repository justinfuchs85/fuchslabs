# Fuchs Labs kit

The shared fingerprints for every Fuchs Labs app: Family Betz, Fuchs Bucks, Kept, and Nota.

The goal is "same studio," not "same app." Each app keeps its own palette, layout, display font, and personality. These are the few things every app shares.

## The fingerprints

| | Rule |
|---|---|
| **Ember** `#E8724A` | The studio's signal color. Used for focus rings, text selection, the dot in every app icon, and the studio mark. Apps may use it elsewhere, but these four are mandatory. |
| **Interface type** | Figtree for UI text. Each app picks its own display face for big headings (Family Betz: Bricolage Grotesque, Kept: Barlow Condensed). |
| **Numbers** | JetBrains Mono with tabular figures for anything you'd compare down a column: points, dollars, dates, counts. Use `.fl-num`. |
| **App icons** | Dark rounded square in the app's own color, one glyph drawn as a single rounded stroke in warm white `#F4EFE6`, and exactly one ember dot. Generated by `icons.mjs` so they stay consistent. |
| **Studio mark** | The fox: two interlocking strokes (shared with Fox Consulting Group), solid ember, beside "Made by Fuchs Labs" in each app's About / settings / footer. `.fl-signature`. |
| **Shape and motion** | Radii 8 / 12 / 16 / 24 / pill. One easing curve, `cubic-bezier(.2,.8,.2,1)`, 180ms. Respect reduced motion. |

## Voice

Every app talks like the same person: dry, direct, a little sarcastic, never mean.

- Say what happened, plainly. "Settled. Points paid out." not "Success!"
- Errors say what went wrong and what to do. No apologies, no "Oops!"
- One joke per screen, maximum. Usually in an empty state or a confirmation, never in an error.
- Teasing is fine. Punching down is not.

## Files

- `fuchs-labs.css`: tokens, focus ring, selection, `.fl-num`, `.fl-signature`
- `icons.mjs`: the icon template; `node icons.mjs <outDir>` renders every app's icon set (needs `@resvg/resvg-js`)
- `icons/`: rendered icons per app, plus the mark in `fuchs-labs-mark.svg` (ember, the default), `-ink.svg` (for light backgrounds), and `-paper.svg` (for dark)

## Adding a new app

1. Add an entry to `APPS` in `icons.mjs`: a background color and a glyph built from `line()` strokes plus one `dot()`.
2. Render the icons and use them for favicon, Home Screen, and App Store icons.
3. Load Figtree + JetBrains Mono and import `fuchs-labs.css`.
4. Put the signature somewhere quiet (About, settings, or a footer).
